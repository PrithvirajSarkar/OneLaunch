# OneLaunch User Guide

## Getting Started

OneLaunch lets you save frequently used applications, files, folders, and websites into reusable workspaces.

A typical workflow is:

```text
Create Workspace
       ↓
Add Items
       ↓
Save
       ↓
Launch Workspace
```

## Creating a Workspace

1. Open OneLaunch.
2. Select **Add Workspace**.
3. Enter a workspace name.
4. Select **Continue**.
5. Add the items you want.
6. Select **Save Workspace**.

Example:

```text
Coding
├── Visual Studio Code
├── Project Folder
├── GitHub
└── Browser
```

## Adding Items

Select **Add Item** inside the workspace setup screen.

You can add:

### Applications

Use **Browse** and select an application.

`.exe` and `.lnk` files are recognized as applications.

### Files

Use **Browse** and select a file.

### Folders

Use the folder selection option and choose a folder.

### Websites

Select **Website** and enter a URL.

For example:

```text
https://github.com
```

If a valid URL is entered without `http://` or `https://`, OneLaunch adds `https://` automatically.

## Editing a Workspace

From the Home screen:

1. Open the workspace menu.
2. Select **Edit**.
3. Modify the workspace name or items.
4. Select **Save Workspace**.

The workspace's pinned state is preserved while editing.

## Editing an Item

The editing interface depends on the item type.

```text
Website
   ↓
Website input

Folder
   ↓
Folder selection

File / Application
   ↓
File selection
```

Duplicate paths and URLs are checked before the edited item is saved.

## Removing an Item

Open a workspace in edit mode and select the remove option for the item.

The removal becomes permanent when the workspace is saved.

## Launching a Workspace

From the Home screen, select **Launch**.

OneLaunch opens each item according to its type:

```text
Application → Start application
File        → Open file
Folder      → Open folder
Website     → Open browser
```

If an item cannot be launched, OneLaunch displays an error and lets you either continue or stop.

## Searching

Use the search field on the Home screen to find workspaces.

Search is case-insensitive and matches part of the workspace name.

For example:

```text
coding
```

can match:

```text
Coding
Coding - College
Personal Coding
```

## Pinning Workspaces

Frequently used workspaces can be pinned.

Open the workspace menu and select the pin/unpin option.

Pinned workspaces are displayed separately from unpinned workspaces.

The pinned state is saved automatically.

## Deleting a Workspace

Open the workspace menu and select **Delete**.

OneLaunch asks for confirmation before deleting the workspace.

## Unsaved Changes

While creating or editing a workspace, OneLaunch tracks unsaved changes.

Changes include:

- Adding an item
- Editing an item
- Removing an item
- Renaming a workspace

If you leave the screen before saving, OneLaunch warns you about the unsaved changes.

## Dark Mode

OneLaunch supports light and dark themes.

The selected theme is saved automatically and restored the next time the application starts.

The setting is stored locally in:

```text
data/settings.json
```

## Duplicate Protection

OneLaunch prevents duplicate workspace names and duplicate launch items.

Workspace names are compared without regard to letter case.

Launch-item paths and website URLs are checked before adding or editing items.

## Empty Workspaces

A workspace can exist without any launch items.

If you try to launch an empty workspace, OneLaunch displays an informational message instead of attempting to launch anything.

Items can be added later by editing the workspace.

## Corrupted Workspace Data

Workspace information is stored in:

```text
data/workspaces.json
```

If the file contains invalid JSON, OneLaunch:

```text
Detects corruption
      ↓
Creates a backup
      ↓
Loads an empty workspace list
      ↓
Continues running
```

The backup is stored as:

```text
data/workspaces.json.backup
```

## Troubleshooting

### An application no longer launches

The application may have been moved, renamed, or removed.

Edit the item and select the correct application again.

### A file or folder no longer opens

The saved path may no longer exist.

Edit the item and select the correct file or folder.

### A website no longer opens

The website may have changed its URL or become unavailable.

Edit the website item and enter the current URL.

## Runtime Data

OneLaunch stores user-specific data locally:

```text
data/
├── settings.json
├── workspaces.json
└── workspaces.json.backup
```

The `data/` directory is generated by the application and is excluded from Git version control.
